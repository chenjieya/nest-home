## 1. 接口

`GET /api/weather`：按访问者 IP 返回天气。受控反代通过 `X-Real-IP` 提供真实 IP；`TRUST_PROXY=false` 时只使用 TCP 来源地址，忽略转发头。只支持高德能定位的国内公网 IPv4；IPv6、内网或未知地区返回不可用，不冒充服务器所在地。

`GET /api/weather?city=110101`：显式指定六位高德行政区划编码，可用于本地调试。禁止重复参数、任意 URL、Key 和任意 IP 查询参数。

`GET /healthz` 或 `GET /api/weather/health`：进程存活检查，不请求任何第三方、不消耗额度。后者可从 Nest 域名检查完整代理链路；200 不表示供应商当前一定可用。

## 2. 返回结构

```json
{
  "data": {
    "city": "东城区",
    "adcode": "110101",
    "weather": "晴",
    "temperature": 20,
    "temperatureKind": "current",
    "winddirection": "北",
    "windpower": "≤3",
    "updatedAt": "2026-11-04 10:00:00",
    "source": "amap"
  },
  "cached": false,
  "stale": false
}
```

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| data.temperature | number | 摄氏度，可为 0 或负数 |
| data.temperatureKind | string | current 为实时温度；range-midpoint 为备用接口最高最低温度的中间值，不应标为实时温度 |
| data.source | string | amap 或 oioweb |
| data.updatedAt | string | 供应商更新时间，未知为空，不伪造时间 |
| cached | boolean | 是否使用缓存 |
| stale | boolean | 上游失败后使用允许期限内的旧天气，前端必须标识缓存数据 |

所有响应为 JSON，带 `Cache-Control: no-store`，避免代理把某位访客的城市响应共享给其他访客。

## 3. 错误与降级

错误结构：`{"error":{"code":"WEATHER_UNAVAILABLE","message":"天气暂时不可用，请稍后再试"}}`。

| HTTP 状态 | code | 含义 |
| :-- | :-- | :-- |
| 400 | INVALID_REQUEST | 参数格式错误 |
| 404 | NOT_FOUND | 路径不存在 |
| 405 | METHOD_NOT_ALLOWED | 仅支持 GET |
| 429 | RATE_LIMITED | 分钟请求数限制，Retry-After 为 60 秒 |
| 503 | WEATHER_UNAVAILABLE | 定位失败、额度不足、供应商超时或无可用天气 |

优先城市天气缓存，然后高德，再尝试教书先生，最后使用允许期限内的旧缓存。定位缓存为 24 小时；高德失败冷却 60 秒，避免无效 Key 或额度耗尽时重复请求。

旧备用接口无法保证识别请求中的 IP 参数，因此只在返回城市编码或城市名与已知目标一致时使用。定位失败且没有可信的目标城市时不会调用备用接口展示服务器天气。当前备用网站证书异常、在线文档不可访问，适配器按原项目响应字段实现，尚不能保证在线可用。
